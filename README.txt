THE EARLIER ADVANTAGE

A free, offline curriculum of 1,000 standalone chess lessons.

START HERE
Open lesson-0001.html in any modern web browser. Use Previous, Next lesson, or the lesson-number box to move through the course.

STRUCTURE
10 modules × 100 lessons = 1,000 pages. Each page is self-contained: its design, chessboard, lesson, exercises, and answer buttons are embedded in that one HTML file. No internet connection or installation is required.

STUDY METHOD
1. Look at the board before reading.
2. Answer the dark “Pause before revealing” question aloud.
3. Reveal the teaching point.
4. Follow the four-step thinking sequence.
5. Close the page by answering the recall test without looking back.
